# Postman Collection — RemindFlow API v4.3

Coleccion de API Testing sobre RemindFlow v4.3.0.

## Contenido
- 20 requests organizados por entidad
- Autenticacion JWT con token automatico
- CRUD completo de Clientes y Tareas
- Casos negativos: 401, 400, 404
- Assertions en cada request
- Variables de entorno para Local y Produccion

## Como usar
1. Importar `RemindFlow_API.postman_collection.json` en Postman
2. Importar el environment correspondiente
3. Ejecutar POST Login primero
4. Ejecutar el resto de requests o usar Collection Runner
